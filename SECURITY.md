# Security policy

BLACKOUT is early-development software. Do not rely on it as the only protection for valuable or sensitive systems.

Report suspected vulnerabilities privately through GitHub's repository security advisory feature. Include a minimal reproduction and affected commit when possible. Do not publish credentials, private project data, or exploit details for an unpatched issue in a public issue.

The project will acknowledge reports and coordinate a fix and disclosure timeline. No supported-version SLA is promised before a stable release.
